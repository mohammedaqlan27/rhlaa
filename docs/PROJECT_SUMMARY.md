# 🇾🇪 PROJECT SUMMARY
# منصة رحلاء (RHLAA)

## نظرة عامة

رحلاء (RHLAA) هي منصة وطنية متكاملة تم تطويرها بهدف رقمنة قطاع النقل البري وإدارة الرحلات والحجوزات والمدفوعات بين الركاب والسائقين والوكالات ومكاتب النقل.

تم تصميم المشروع ليكون أكثر من مجرد تطبيق حجز رحلات، حيث يهدف إلى إنشاء منظومة تشغيلية متكاملة تدعم:

- الركاب
- السائقين
- الوكالات ومكاتب النقل
- مسؤولي النظام
- الجهات المشرفة
- الجهات الأمنية

---

# المشكلة

في العديد من أنظمة النقل التقليدية تواجه المؤسسات والمستخدمون تحديات متعددة، من أبرزها:

- الاعتماد على العمليات الورقية.
- صعوبة إدارة الحجوزات.
- ضعف توثيق السائقين والمركبات.
- غياب إدارة المدفوعات بشكل منظم.
- عدم وجود كشوفات رقمية للركاب.
- ضعف الرقابة على العمولات والإيرادات.
- غياب آليات التحقق والتوثيق.
